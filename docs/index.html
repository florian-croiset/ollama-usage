ollama-usage

Check your Ollama Cloud usage quota from the terminal, from Python, or in a small desktop widget.

GitHub Changelog Issues

Install

$ pip install git+https://github.com/florian-croiset/ollama-usage

Create an API key at ollama.com/settings/keys, then:

$ export OLLAMA_API_KEY=your_key
# PowerShell: $env:OLLAMA_API_KEY = "your_key"
$ ollama-usage

No API key? Log in to ollama.com with Firefox and the session cookie is read automatically. With another browser, copy the __Secure-session cookie and pass it with --cookie or OLLAMA_BROWSER_COOKIE (Chromium-based browsers are not read automatically).

Desktop notifications need an extra:

$ pip install "ollama-usage[notify] @ git+https://github.com/florian-croiset/ollama-usage"

Example output

$ ollama-usage
Monthly : 18.4% used
    deepseek-v3.1:671b       112 req
    gpt-oss:120b              64 req
    web search                21 req
Spend   : $1.20 (last 4 weeks)

With the session cookie instead of an API key, you also get the plan, reset date, share per model and credits balance.

Features

Every plan
Free, Pro, Max and Team monthly credits, and legacy session / weekly limits.
Scripting
--json, --watch --interval 60, and --quiet --alert 80 (exit code 1 above 80%).
Notifications
--notify (needs the notify extra) warns once when a quota crosses --notify-threshold.
Widget
--widget opens an always-on-top window with usage and reset countdown (needs tkinter).
Python library
get_usage_api(key) and get_usage(cookie) return a plain dict.
Minimal requirements
Python 3.9+, no required dependencies. Windows, macOS and Linux.

Full documentation in the README. Uses an undocumented Ollama endpoint and scrapes ollama.com/settings; either may change.
