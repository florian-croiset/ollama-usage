ollama-usage

Your Ollama Cloud quota, credits and per-model usage, from the official API: in the terminal, in Python, in Rust or as JSON.

GitHub Releases Changelog Issues

Install

$ pip install git+https://github.com/florian-croiset/ollama-usage

This installs the Python package and the ollama-usage command, and compiles them, which needs Rust. Each release also provides prebuilt wheels and standalone binaries that need nothing else.

Create an API key at ollama.com/settings/keys, then:

$ export OLLAMA_API_KEY=your_key
# PowerShell: $env:OLLAMA_API_KEY = "your_key"
$ ollama-usage

The quota windows and credits come from /api/balance, and the requests, cost and tokens per model from /api/usage, both documented by Ollama. The plan name comes from /api/me, of which only the plan is read.

Features

Every plan
Monthly included credits on current plans, session and weekly windows on plans from before the 2026-08-31 pricing change, and purchased credits.
Per-model usage
Requests, cost and tokens over the last 24 hours, 7 days or 30 days with --range.
Scripting
--json follows a versioned schema; --quiet --alert 80 exits with 1 at 80 %, and every other outcome has its own exit code.
Python and Rust
Client(key).fetch() returns typed, read-only objects; the Rust crate is the same core.
Careful with your key
Sent only to ollama.com, never logged, nothing written to disk, no telemetry.
